# ZL Useful Projects

A small GitHub Pages-ready collection of practical browser tools.

## Projects

- Material Estimator: calculate sheet, edge, labor, and loss totals.
- Quote Builder: prepare a clean customer-facing quote summary.
- Work Tracker: manage lightweight project tasks in local browser storage.

## Use

Open `index.html` in a browser. No build step is required.

## Deploy

Push this folder to a GitHub repository and enable GitHub Pages from the repository settings.
