# JS Algorithm Lab

A small JavaScript practice repository with readable implementations, examples, and a tiny test runner.

## Included

- Binary search
- Debounce and throttle helpers
- LRU cache
- Event emitter
- Deep clone utility

## Run

```bash
node test/run-tests.mjs
```

## Why

This project is designed as a clean coding-practice repo: short modules, simple tests, and examples that are easy to inspect from GitHub.
